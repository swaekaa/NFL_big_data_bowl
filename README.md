# NFL Big Data Bowl 2027 — Combine to NFL Performance

## Project Overview

Competition-level research pipeline for **Kaggle NFL Big Data Bowl 2027**.

Goal: Discover novel, actionable linkages between NFL Combine 10 Hz tracking data and subsequent rookie NFL regular-season performance.

## Research Philosophy

- **Novelty over accuracy** — a simple, interpretable metric with a strong football story beats a black-box model.
- **Player is the unit of analysis** — tracking frames are NOT independent observations.
- **Temporal correctness** — Combine features must be prospective (no future information leakage).
- **First-season focus** — link Combine to rookie-year NFL performance for clean scouting interpretation.
- **Caution with confounders** — control for scheme, role, snap count, opponent quality.
